# Aturan untuk AI Agent

## Push ke GitHub
- **DILARANG** melakukan `git push` ke remote GitHub tanpa perintah/persetujuan eksplisit dari user.
- Agent **boleh** menyarankan atau menawarkan opsi push, tetapi **kendali tetap di user**.
- Agent hanya boleh push jika user sudah memberikan konfirmasi jelas (misal: "push sekarang", "iya push aja", "gas").
